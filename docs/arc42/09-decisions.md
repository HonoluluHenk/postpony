# 9. Architecture Decisions

All architecture decisions live in [`docs/adr/`](../adr/), one file per decision, numbered from 0001.

See the [ADR index](../adr/) for the full list and statuses. Note that several early ADRs have been superseded or withdrawn as the system moved from Firestore/Docker to Cloudflare Workers + Turso + SQLite; the supersession chain is recorded in each affected ADR's status.
